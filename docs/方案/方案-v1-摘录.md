# Logseq 本机运行方案 v1

## 1. 结论

推荐官方桌面发布包：下载匹配系统的包→打开→建测试图谱→写笔记。新手只需使用功能，无需先搭编译环境。这是 [官方 README](https://github.com/logseq/logseq/blob/master/README.md) 的最短使用路线。优先选择可在项目目录解压或运行的官方包，避免系统安装器。

源码是开发备选，当前官方已用 **pnpm**，不要照旧执行 Yarn/npm 教程，不重写应用。[官方开发指南](https://github.com/logseq/logseq/blob/master/docs/develop-logseq.md)

2026-10-15 核对：[最新发布页](https://github.com/logseq/logseq/releases/latest) 指向 2.0.2（Beta Testing）；执行前重新确认。README 提醒数据库版为 beta，首次只建测试图谱并准备备份。复习清单先采用普通页面加待办，不默认装插件。

项目固定放 `/workspace/logseq-setup/logseq`。本轮只写方案，未检查本机依赖，未下载软件、克隆、安装或启动。

## 3. 逐步命令与效果验证

### 推荐：桌面发布包

无需克隆和源码依赖。先确认操作系统、架构、版本、实际官方资产 URL、目标目录不存在及运行授权。Linux 如有匹配 AppImage，可使用以下模板；占位 URL 必须替换后才执行：

```bash
# mkdir 失败就停止，禁止删除或覆盖原目录。
mkdir /workspace/logseq-setup/logseq
mkdir /workspace/logseq-setup/logseq/app
curl -fL --output /workspace/logseq-setup/logseq/app/Logseq.AppImage '<核对后的官方资产URL>'
chmod u+x /workspace/logseq-setup/logseq/app/Logseq.AppImage
/workspace/logseq-setup/logseq/app/Logseq.AppImage
```

macOS/Windows 选对应官方包，优先项目内解压或运行；需要项目外安装时先说明路径并确认。Linux 缺 FUSE 或运行库先报告，不直接 sudo 安装或关闭 Electron 沙箱。

打开应用，创建“验收图谱”。若支持选目录，使用 `/workspace/logseq-setup/logseq/graphs/demo`。数据库版可能把数据放在用户配置目录；先核对并确认实际写入位置，不能承诺所有数据自动位于项目目录内。

### 备选：源码，克隆→依赖→启动

以下为 macOS/Linux 官方路径，增加目录保护。仅在用户确认源码路线及相关动作、工具齐全后执行。[官方开发指南](https://github.com/logseq/logseq/blob/master/docs/develop-logseq.md)

```bash
if [ -e /workspace/logseq-setup/logseq ]; then
  echo '目标已存在，停止，禁止覆盖。'
  exit 1
fi
cd /workspace/logseq-setup
git clone https://github.com/logseq/logseq /workspace/logseq-setup/logseq
cd /workspace/logseq-setup/logseq
git rev-parse HEAD
# 先阅读适用 AGENTS.md、README、开发指南、package.json 与锁文件。
# 核对版本、下载及安装授权后：
pnpm install
# 确认启动本机开发服务后：
pnpm watch
```

等待编译完成，在本机浏览器打开 `http://localhost:3001`。以 checkout 的官方说明和实际日志为准，不能把进程存活当成启动成功。

如果确实需要源码桌面版，官方另要求 static 内的依赖；先按该提交说明核对 static 生成时机，目录不存在就查原因，不伪造目录：

```bash
cd /workspace/logseq-setup/logseq/static
pnpm install
cd /workspace/logseq-setup/logseq
# 保持 pnpm watch 运行，等待 app 和 electron 编译完成。
# 关闭已有 Logseq 桌面应用，然后在另一个终端：
pnpm dev-electron-app
```

两条路线共用目标路径，不可在已有桌面包目录上克隆。切换路线先确认保留与迁移方案，不自行删除目录。

### 验证四项效果

在今天的 Journals/每日笔记页面逐块输入：

```text
今天开始使用 Logseq。
学习 [[双链测试]] #学习
复习 [[双链测试]] [[复习清单]]
```

1. 每日笔记：今天日期下能看到记录，重新打开应用后仍在。
2. 双链引用：点击双链测试，写一句说明；在 Linked References/引用区找到今天笔记的来源，点击可回到原块。反向引用由 Logseq 自动产生。
3. 标签图谱：点击学习标签能找到相关记录；打开图谱、清除筛选，验证每日笔记、双链测试、学习的关联。若默认隐藏标签节点，在图谱设置启用相应显示并记录。版本不支持预期效果时说明实际情况，不假报通过。
4. 复习清单：打开复习清单页面，新增“复习双链测试”，用界面待办操作设为未完成；刷新后保留，勾选完成后状态保存。这是手工复习清单。用户要求自动间隔复习时，再核对该版本内置 Cards 功能并另行确认。
